## 💻 Getting Started Locally

Clone the repository and run the development server locally:

```bash
# 1. Clone the repository
git clone https://github.com/Action-kamen257/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Production Build
```bash
# Build optimized static/SSR bundle
npm run build

# Start production server
npm run start
```

## 📝 How to Add New Projects / Dossiers

To add a new project to the portfolio:

1. Open [`src/data/dossiers.ts`](src/data/dossiers.ts).
2. Append a new project object to the `DOSSIERS` array with:
   - `id`: Unique URL slug (e.g., `'my-new-ai-project'`)
   - `codeName`: Comic classification code (e.g., `'PROJECT_APOLLO // V1'`)
   - `title`: Project title
   - `category`: `'ai' | 'gis' | 'robotics' | 'fullstack'`
   - `stats`: Key metrics and benchmarks
   - `caseStudy`: Problem statement, architecture, results, and learnings.
3. Save the file — the Home page and dedicated case study route `/projects/[slug]` will automatically generate and render it!
